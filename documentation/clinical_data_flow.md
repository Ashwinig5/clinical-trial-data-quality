# Clinical Data Flow

## Overview

Clinical trial data is received from clinical trial sites and reviewed for
accuracy, completeness, consistency, and validity.

When a discrepancy is identified during data review, a query is raised with
the clinical trial site for clarification or correction.

The site provides a response or confirms the data. The data is then reviewed
and verified to ensure that the discrepancy has been resolved. Once the issue
is appropriately resolved, the query is closed.

The cleaned and validated data is then analysed to assess overall data quality.

## Clinical Data Flow

        ↓
    Yes → Query Raised
        ↓
